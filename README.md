# CrossZeroTMA — Игра «Крестики-Нолики» как Telegram Mini App

Проект представляет собой классическую игру **«Крестики-нолики»**, реализованную в виде **Telegram Mini App (TMA)** с интеграцией с Telegram-ботом на Python (библиотека `aiogram 3`).

## 🌟 Основные возможности

* **Игра внутри Telegram:** Запуск игры прямо в интерфейсе Telegram в один клик.
* **Адаптивный дизайн:** Игра автоматически подстраивается под тему оформления Telegram (светлая/тёмная) благодаря интеграции с Telegram WebApp CSS-переменными (`--tg-theme-*`).
* **Анимация победы:** Рисуется линия, перечёркивающая выигрышную комбинацию, и подсвечиваются победившие ячейки.
* **Интеграция с ботом:** Результат игры (победа одного из игроков или ничья) отправляется обратно боту через `tg.sendData()`. Бот реагирует на это событие и присылает сообщение с поздравлением или объявлением ничьей в чат.

---

## 📁 Структура проекта

* `index.html` — Фронтенд игры (HTML5, CSS3, чистый JavaScript). Использует официальный Telegram WebApp SDK для взаимодействия с Telegram.
* `crosszero.py` — Бот на Python с использованием асинхронной библиотеки `aiogram 3`. Регистрирует команды, открывает WebApp и обрабатывает результаты игр.

## 🚀 Как запустить проект

Для полноценной работы проекта вам понадобятся:
1. Захостить веб-страницу `index.html` на любом публичном веб-сервере с поддержкой HTTPS (например, GitHub Pages).
2. Настроить Telegram-бота у `@BotFather` и запустить скрипт `crosszero.py`.

### Шаг 1. Развёртывание фронтенда (GitHub Pages)

Поскольку Telegram требует, чтобы все Mini Apps работали по защищённому протоколу HTTPS, самым простым бесплатным решением является использование **GitHub Pages**:

1. Создайте публичный репозиторий на GitHub (например, `CrossZeroGame`).
2. Загрузите файл `index.html` в этот репозиторий.
3. Перейдите в **Settings** (Настройки) -> **Pages** вашего репозитория.
4. В разделе **Build and deployment** выберите ветку `main` (или `master`) и нажмите **Save**.
5. Через пару минут GitHub предоставит вам HTTPS-ссылку вида `https://<ваше-имя-пользователя>.github.io/CrossZeroGame/`.

### Шаг 2. Настройка Telegram-бота

1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Создайте нового бота с помощью команды `/newbot`, следуйте инструкциям и получите **API Токен** бота.
3. Откройте файл `crosszero.py` и настройте конфигурацию:
   * Замените значение переменной `BOT_TOKEN` на полученный от `@BotFather` токен:
     ```python
     BOT_TOKEN = 'ВАШ_API_ТОКЕН'
     ```
   * Замените значение `MINI_APP_URL` на URL-адрес вашей игры, полученный на Шаге 1:
     ```python
     MINI_APP_URL = 'https://<ваше-имя-пользователя>.github.io/CrossZeroGame/'
     ```

### Шаг 3. Установка зависимостей и запуск бота

Бот написан на Python с использованием библиотеки `aiogram` третьей версии.

1. Установите библиотеку `aiogram` (если она ещё не установлена):
   ```bash
   pip install aiogram
   ```
2. Запустите скрипт бота:
   ```bash
   python crosszero.py
   ```

## 🎮 Как играть

1. Зайдите в чат с вашим созданным ботом в Telegram.
2. Отправьте команду `/start`. Бот пришлёт приветственное сообщение и кнопку **«🚀 Открыть игру крестики-нолики»**.
3. Нажмите на кнопку — откроется окно игры.
4. Совершайте ходы по очереди за **X** (красные) и **O** (синие).
5. При завершении игры (победа или ничья) результат через секунду отправится обратно в чат с ботом, и бот пришлёт сообщение с итогами.

## 🛠️ Технологии

* **Frontend:** HTML5, CSS3 (CSS Variables для тем оформления Telegram), Vanilla JavaScript.
* **Backend:** Python 3.8+, [aiogram 3.x](https://github.com/aiogram/aiogram) (асинхронная библиотека для Telegram Bot API).
* **API:** Telegram WebApp SDK.
